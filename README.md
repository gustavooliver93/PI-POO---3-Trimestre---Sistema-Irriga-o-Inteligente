## 🌾 Sobre o Projeto
O **AgroTech** é um sistema em Java desenvolvido para automatizar a verificação do nível de umidade do solo em talhões de cultivo de Soja e Milho, calculando a necessidade exata de irrigação por hectare.

---

## 🛠️ Tecnologias e Conceitos Aplicados
* **Lógica de Programação:** Variáveis, estruturas condicionais (`if/else`), laços de repetição (`for`), funções e validações de dados.
* **Programação Orientada a Objetos (POO):** Encapsulamento, Abstração, Herança e Polimorfismo.
* **Linguagem:** Java.
